# 需求整理（v4 简化版）

## 一句话
把 Muse 的“想法画布”和 Manus 的“agent 替你干活”合在一起，再加上项目管理：每个人都能用 agent 同时推进多个项目，像经营一家一人公司。

## 参考的两种产品形态
- **Muse**：一块自由的画布，想法以卡片形式随手摆放、分组、连线。优点是想得开、不打断思路。
- **Manus**：交代一个任务，agent 在云端电脑里一步步执行，你能看到它每一步在做什么，最后交出结果。
- **我们要补的**：两者都不管“项目”。没有目标拆解、进度、花费、审批和验收。

## 需求清单
| # | 需求 | 在 demo 里的位置 |
|---|---|---|
| 1 | 随手记想法，文字或语音，手机和网页都能用 | 画布底部的输入框和麦克风 |
| 2 | 想法以卡片形式放在画布上，可以拖动、整理 | 画布 |
| 3 | 选中几张卡片，一键变成项目；有不清楚的地方 AI 先问 | “变成项目”后弹出一个问题 |
| 4 | 项目有高层目标，一层层拆到具体任务 | 项目页左侧的计划 |
| 5 | 每个任务交给 agent 执行，能看到它一步步在做什么 | 项目页右侧的 agent 面板 |
| 6 | 可以给不同任务选不同的 agent / 模型，或者自动选 | 任务上的模型标签 |
| 7 | 看得到进度、卡在哪、花了多少钱和 token、还要多久、还要花多少 | 项目页顶部 |
| 8 | 花钱继续做之前要你批准 | “开始下一个任务”按钮上写着预计花费 |
| 9 | 每个任务完成都有 demo（截图、测试结果），你来验收或打回 | agent 面板里的结果和“通过 / 让它改” |
| 10 | 每个项目有自己的上下文 | 暂未放进 demo，下一步再加 |

## 暂时不做
多人协作、非软件类项目的 demo、复杂的授权等级。
